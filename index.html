Flask · 관리자 화면 · OpenAI

03

해외 광고 문구 점검

Python · 규칙 엔진 · OpenAI

04

콘텐츠 제작

상세페이지 · SNS 콘텐츠 자동 생성

대시보드에서 채널별 톤에 맞춰 카드뉴스 · 이미지 · 숏폼을 만들고(카드뉴스 제작시간 64.7% 단축), 5일간 게시물 91개로 릴스 누적 조회 4,961회를 기록했습니다.

Streamlit · OpenAI · UNI-PASS API
